Open Weather Application

Scope of the project:
Understand the architecture behind web applications.
Undrestand how to store data into databases.
Understand how to gather data from APIs, normalize values, store in database and show on the web apps front end.
Learn to use React, Node.js, PostegreSQL

Objective:
Create a web app using open weather api to show the weather for a specific city for this day, week, month.

Example : https://openweathermap.org/
use openweathermap API key (1000 free api requests)npm install
